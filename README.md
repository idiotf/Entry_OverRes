# Entry OverRes
엔트리 작품에서 이미지·소리를 원본 그대로 업로드해 줍니다.

엔트리에 이미지나 소리를 업로드했는데, 품질이 떨어지는 경우가 있었나요?
이 확장 프로그램을 사용하면 원하는 이미지·소리를 원본 그대로 업로드할 수 있습니다.
지금 바로 이 확장 프로그램을 설치한 뒤, 차이를 느껴보세요!

## 주의 사항
- 업로드 파일 중 하나라도 svg가 있는 경우, 모든 파일에 기존의 업로드 방식이 사용됩니다. 만약 svg가 포함된 경우 따로 업로드해 주세요.
- 엔트리 그림판에서는 이미지가 잘려 보일 수 있습니다.
- 작품 초기 로딩이 오래 걸릴 수 있습니다.
- 소리 편집이 제대로 되지 않거나, 저장 시 음질이 저하될 수 있습니다.
